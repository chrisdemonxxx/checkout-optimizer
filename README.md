## Quick Install
1. Download the [latest release](https://github.com/chrisdemonxxx/checkout-optimizer/releases)
2. Upload to `/wp-content/plugins/`
3. Activate in WordPress admin
4. Go to WooCommerce → Checkout Optimizer
